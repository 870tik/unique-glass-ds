GLASS

ガラスをベースにした、
ユニークなデザインシステム。

ボタンも、カードも、入力欄も — 背後の光を屈折させるガラスで組んだ Web UI コンポーネント集です。ビルド不要、HTML と CSS を置くだけで動きます。

LENS
01 — 見た目のちがい

縁のにじみが、本物。

よくある「すりガラス風」は、実はただのぼかしフィルタです。この素材は背後の光を 実際に屈折させているので、本物のレンズと同じ色のにじみ（虹）が縁に出ます。

縁を、よく見てください。

背後の同心円がカードの縁で曲がって、赤と青ににじんでいます。 カーソルを縁に沿って動かすと、虹色の光が追いかけてきます。 指で押さえている間、縁に虹色の光が点きます。

ぼかしの重ね塗りではなく、屈折の実計算です。

02 — 動きのちがい

触ったときだけ、
生きている。

押すと潰れ、離すとぷるんと戻り、触れると光が応える。 でも誰も触っていないときは、完全に静止しています。 勝手に動き続ける装飾はひとつもありません — 動きはぜんぶ、操作への返事です。

カーソルを乗せると — 押す前に — レンズが少しだけ締まります。 Tab キーでフォーカスしてしばらく待つと、縁の光がゆっくり明滅します。 まるで、見つめられて呼吸しているように。 触れた瞬間に縁が光り、押すと屈折ごと締まり、離すとぷるんと戻ります。 指を離れたガラスは、また静かになります。
03 — あなた専用

ユーザーによって、
デザインが微妙に変わります。

このページの色合い・光の角度・動きのクセは、ブラウザごとに少しずつ違う値で 生成されています。いまあなたが見ている画面は、正確には、あなたにしか見えていません。 隣の人が開くと、光の色が違います。

04 — 中身

新しい形のデザインシステムとして

単なる見た目の研究ではなくあらゆるサービスに応用可能な新しい形のデザインシステムとして、 415個のトークン、53個のコンポーネントが用意されています。生成AIを用いたサービスの UI/UXデザインに利用することができるよう全パーツ利用ルールが定まっており、 ルール違反は ClaudeCode のチェックで弾けます。

05 — 使い方

コピーして、置くだけ。

npm もビルドツールも要りません。3つのファイルを読み込んで、 クラス名を書けば、その要素はガラスになります。

1

ファイルを置く

css/ と js/ をプロジェクトにコピーして、HTML から3行で読み込みます。依存はゼロです。

2

クラス名を書く

部品は HTML のクラス名だけで組めます。lg-glass を付けた要素が、屈折するガラスになります。

3

カタログからコピペ

53部品の実物とコードはカタログに。部品ごとに「いつ使うか」の文書が付いています。

<link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/liquid-glass.css">
<script src="js/liquid-glass.js"></script>

<button class="lg-glass lg-button lg-button--primary" data-lg-gel>
  送信する
</button>
