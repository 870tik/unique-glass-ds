# Combobox — 使用用途

**層**: トリガー = ガラス field / パネル = ガラス（一時面）　**ガラス予算**: 予算外

## いつ使う
- 大量候補からの検索型選択（顧客名・タグ等）

## いつ使わない（代替）
- 候補が少ない → select
- 自由入力が主で候補は補助 → field + datalist 的運用は本システム外

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 入力でフィルタ・Enter で先頭確定・`lg-change` 発火

## 組み合わせ
- form-row 内（編集画面の関連エンティティ選択）

## a11y
- 絞り込み結果 0 件時の挙動をヘルプで補足

## AI への指示
- 表示ラベルと値が違う場合は data-lg-value / data-lg-label を使う
