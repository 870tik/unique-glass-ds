# Select — 使用用途

**層**: トリガー = 塗り / パネル = ガラス（一時面）　**ガラス予算**: 一時面は予算外

## いつ使う
- 既知の選択肢からの単一選択（5〜15個目安）

## いつ使わない（代替）
- 選択肢が多く検索したい → combobox
- 2〜4個の排他即決 → segmented / radio

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 選択で `lg-change`（detail.value）。caret は chevron-down アイコン

## 組み合わせ
- toolbar の絞り込み・form-row 内

## a11y
- パネルは listbox/option を自動付与。キーボード移動対応済み

## AI への指示
- 既定値は「最も安全な選択肢」に。プレースホルダ選択のままを許さない設計に
