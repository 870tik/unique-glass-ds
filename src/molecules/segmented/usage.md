# Segmented — 使用用途

**層**: 塗り容器 + 共有ピル　**ガラス予算**: 予算外

## いつ使う
- 2〜5個の**排他**切替で、結果が即時反映されるもの（期間・表示モード）

## いつ使わない（代替）
- ページ列挙 → nav
- 複数選択 → chip

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- lg-nav のピル機構を共有（gel 滑走）。role=tablist

## 組み合わせ
- toolbar の左端が定位置

## a11y
- aria-selected が状態。ラベルは短く（7d/30d 等）

## AI への指示
- 5個を超えたら select へ変換する
