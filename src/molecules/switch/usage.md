# Switch — 使用用途

**層**: 塗り → **操作中のみノブがガラス化**（公理6の例外）　**ガラス予算**: 予算外

## いつ使う
- 即時反映される on/off 設定

## いつ使わない（代替）
- 送信ボタンで確定するフォーム項目 → checkbox
- 3値以上 → select / segmented

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- ノブは gel バネで滑走。input[type=checkbox] が状態の実体

## 組み合わせ
- settings のパネル内・drawer 内

## a11y
- ラベルは label 要素で包む（クリック領域拡大込み）

## AI への指示
- ラベルは「有効時に何が起きるか」を書く（Auto-send receipts）
