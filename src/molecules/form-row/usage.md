# Form row — 使用用途

**層**: コンテンツ層（レイアウト）　**ガラス予算**: —

## いつ使う
- ラベル + 入力 + ヘルプ/エラーの1行分の定型

## いつ使わない（代替）
- ラベル不要の検索単体 → field 単体

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `.is-error` で help が赤化し field にリング。gap はトークン準拠

## 組み合わせ
- form-layout（編集/新規）・settings のパネル内が定位置

## a11y
- label[for] と input[id] を対応させる。エラー文は具体的に

## AI への指示
- 1行1論点。複数入力を1 row に詰めない（checkbox 群のみ例外）
