# Number input — 使用用途

**層**: ガラス（field 拡張）　**ガラス予算**: 予算外

## いつ使う
- 増減の刻みが意味を持つ数値（数量・金額ステップ）

## いつ使わない（代替）
- 自由入力の大きな数値 → 通常 field + 検証
- 範囲の連続値 → slider

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `.lg-step`（data-step）で増減。min/max/step を尊重し input/change を発火

## 組み合わせ
- form-row 内。金額は step=10000 のような業務単位で

## a11y
- ステップボタンに aria-label（増やす/減らす）

## AI への指示
- 上限のある数量には max を必ず設定（UI で不正値を作らせない）
