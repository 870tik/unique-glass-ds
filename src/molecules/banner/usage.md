# Banner — 使用用途

**層**: コンテンツ層（不透明）　**ガラス予算**: —

## いつ使う
- **ページに留まる**通知（メンテ予告・恒常的な警告・未完了の設定）

## いつ使わない（代替）
- 操作の結果通知（消えてよい）→ toast
- 入力単位のエラー → form-row の .is-error

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 変種: 中立 / `.is-positive` / `.is-danger`。`.lg-banner-close` で退場（fade）

## 組み合わせ
- page 先頭か対象セクション直上。1画面1枚まで

## a11y
- 重要バナーは role=alert 相当の文脈で（実装はページ判断）

- 本文に解決アクションへの導線を含める（「設定を確認」等）
