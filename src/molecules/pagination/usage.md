# Pagination — 使用用途

**層**: 塗り　**ガラス予算**: 予算外

## いつ使う
- 一覧の頁送り（サーバ分頁）

## いつ使わない（代替）
- 少件数 → 全件表示
- 無限に続くフィード → 無限スクロール（本システム外の判断）

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `.lg-pagination-item`。現在頁は `aria-current="page"` で ink 反転。前後は chevron アイコン

## 組み合わせ
- table を持つ panel の右下

## a11y
- 前へ/次へに aria-label。disabled は先頭末尾で

## AI への指示
- 総頁が多いときは 1 2 3 … N 形式に省略
