# Table — 使用用途

**層**: コンテンツ層（**ガラス化禁止**）　**ガラス予算**: —

## いつ使う
- 構造化データの一覧。`--compact` で密度アップ

## いつ使わない（代替）
- 2〜3項目のメタ → kv
- カード的な閲覧が主 → card グリッド

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `--responsive` は **td に data-th 必須**（SP でラベル付きカード化）。数値列 `.num`

## 組み合わせ
- panel 内に置き、行操作は ⋯ menu、状態は badge、頁送りは pagination

## a11y
- th スコープを崩さない。行クリックより明示的な操作列を推奨

## AI への指示
- 列は5〜6本まで。溢れる情報は detail 画面へ送る
