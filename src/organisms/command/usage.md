# Command palette — 使用用途

**層**: ガラス（一時面）+ scrim　**ガラス予算**: 予算外

## いつ使う
- キーボード主導の横断操作（⌘K）。SaaS の旗艦導線

## いつ使わない（代替）
- 主要導線の代替にしない（可視ナビは必須のまま）

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- ⌘K/Ctrl+K 自動。入力フィルタ・矢印/Enter・empty 表示

## 組み合わせ
- 項目にはショートカットヒント `.hint` を添えられる

## a11y
- role=dialog。開いたら入力にフォーカス（自動）

## AI への指示
- 項目文言は「動詞 + 対象」（Create invoice）。同義語を data 属性で持たせない（シンプル維持）
