# Panel — 使用用途

**層**: コンテンツ層（不透明）。**ガラスの相方**　**ガラス予算**: —

## いつ使う
- 読む・見るまとまりの器（表・統計・設定群・本文）

## いつ使わない（代替）
- 押せる1枚もの → card

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- surface 連動の面色。内側の角丸は `.lg-concentric`

## 組み合わせ
- table / stat / form-row / kv の親として最頻出

## a11y
- 見出し（lg-type-heading）を先頭に置く

## AI への指示
- 迷ったら panel（ガラスにするのは操作系だけ・公理6）
