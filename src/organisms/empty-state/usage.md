# Empty state — 使用用途

**層**: コンテンツ層　**ガラス予算**: —

## いつ使う
- データ0件の初期状態・検索0件（アイコン + 見出し + 補足 + 次の一手）

## いつ使わない（代替）
- 読み込み中 → skeleton / spinner（待ちと空は別状態）

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- glyph は data-lg-icon。アクションは lg-button 1つ

## 組み合わせ
- table / 一覧の代わりに panel 内へ

## a11y
- 見出しで状態を明言（「まだ〜がありません」）

## AI への指示
- 補足文には「最初の一歩で何が起きるか」を書く。責める文言（「見つかりません」だけ）で終えない
