# Context menu — 使用用途

**層**: ガラス（一時面）　**ガラス予算**: 予算外

## いつ使う
- 右クリックの文脈操作（テーブル・キャンバス系）

## いつ使わない（代替）
- モバイル主体の画面（右クリックが無い）→ 行の ⋯ menu を併設

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `data-lg-context="#panel-id"`。パネルは body 直下に置く

## 組み合わせ
- 必ず同等操作の可視導線（⋯）を併設（発見可能性）

## a11y
- キーボードからは ⋯ メニューが代替経路

## AI への指示
- context 専用の機能を作らない（隠し機能化する）
