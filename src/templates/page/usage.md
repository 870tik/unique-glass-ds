# Page（共通の器） — 使用用途

**層**: コンテンツ層レイアウト（最大幅1200 + 余白 + セクション gap 32）

## いつ使う
- shell 内の**全画面**の器。直下にセクションを並べると余白リズムが自動で付く

## いつ使わない（代替）
- shell 外の standalone（focus / auth はそれ自体が器）

## 契約の要点
- `display` を上書きしない（flex gap が死ぬ・docs/08 B1 の事故例）
- toolbar 直下だけ gap が 16 に自動で詰まる（グルーピング）
