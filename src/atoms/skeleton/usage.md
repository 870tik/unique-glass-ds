# Skeleton — 使用用途

**層**: コンテンツ層　**ガラス予算**: —

## いつ使う
- 構造が既知のコンテンツの読込中プレースホルダ（行・アバター・見出し）

## いつ使わない（代替）
- 一瞬で終わる読込（ちらつく）→ 何も出さない
- 構造未知の待ち → spinner

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- `--text` / `--circle`。寸法はページ側で指定。shimmer は reduced-motion で静止

## 組み合わせ
- table 行・kv・card の形をなぞって配置

## a11y
- `aria-hidden` + 読み込み領域に aria-busy を推奨

## AI への指示
- 実コンテンツと同じレイアウト骨格で置く（形が違うとガタつく）
