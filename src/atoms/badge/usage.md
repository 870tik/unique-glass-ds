# Badge / Dot — 使用用途

**層**: コンテンツ層（塗り）　**ガラス予算**: —

## いつ使う
- ステータスの表示（Paid / Pending / Overdue 等）。テーブル・詳細ヘッダに
- `.lg-dot` は稼働状態の点

## いつ使わない（代替）
- 操作可能な絞り込み → chip
- 数値の強調 → stat

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 変種: `.is-positive` / `.is-danger`（+ 既定の中立）。uppercase・micro サイズ

## 組み合わせ
- table のステータス列・detail の見出し横が定位置

## a11y
- 色のみで意味を伝えない（テキストが本体）

## AI への指示
- 状態語は短く（1〜2語）。文章を入れない
