# Prose — 使用用途

**層**: コンテンツ層　**ガラス予算**: —

## いつ使う
- 説明文・本文ブロックの器（body サイズ・行送り1.7・p 余白）

## いつ使わない（代替）
- UI ラベル → type ユーティリティを直接

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 内部の p は margin 管理済み。見出しは lg-type-* を併用

## 組み合わせ
- panel / modal の本文・detail の説明領域

## a11y
- 行長は form-max(640px) 目安に抑える

## AI への指示
- ガラス上に長文 prose を置かない（可読性予算・公理6）
