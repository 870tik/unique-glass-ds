# Icon button — 使用用途

**層**: 塗り（非ガラス）。ガラス上・コンテンツ層どちらでも可　**ガラス予算**: 予算外（塗り）

## いつ使う
- ツールバー・テーブル行・カード隅の省スペース操作（⋯ メニュー・閉じる・テーマ切替）

## いつ使わない（代替）
- 主要 CTA → lg-button（ラベル付き）
- 3つ以上並ぶ操作群 → menu に畳む

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- 中身は `<i data-lg-icon="...">` 1つ。円形・外径 `--lg-icon-button-size`(34px)

## 組み合わせ
- lg-menu-anchor のトリガーとして最頻出
- data-lg-tooltip でラベル補足を推奨

## a11y
- **`aria-label` 必須**（アイコンだけでは読み上げ不能）

## AI への指示
- テキストで説明できる余白があるなら lg-button を優先する
