# Spec tag — 使用用途

**層**: 塗り（観測機器の意匠）　**ガラス予算**: —

## いつ使う
- 素材・部品の**実物性の申告**（ca 6px・k 440 等）。ショーケース・技術的な文脈で

## いつ使わない（代替）
- 一般ユーザー向け画面の装飾（意味のない数値表示は禁止）

## 契約の要点
- マークアップ正典: 同フォルダの `.html`
- mono・uppercase・hairline 枠。**値は実トークン値**を書く（飾りの数字は不可）

## 組み合わせ
- specimen カード・catalog ストーリー・LP の技術訴求と併用

## a11y
- 記号 `·` は `<span class="sep">` で（読み上げノイズ低減）

## AI への指示
- 書く値は tokens の $value と一致させること（乖離したら lint 級の違反と考える）
