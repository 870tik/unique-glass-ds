# 00 — Philosophy: このガラスは何でできているか

このデザインシステムは値の集合ではなく、**ひとつの架空の物質の記述**である。
blur の px 数もバネの硬さも、ここで定義する物質の物理からの演繹にすぎない。
値に迷ったら物理に戻ること。物理に反する値は、たとえ美しくても却下される。

v1 は Apple Liquid Glass（WWDC 2025）への忠実から出発した。v2（R11）で
これを分岐し、**独自の物質「Prism」**を既定とする。Apple 相当の控えめな
振る舞いは theme apple-quiet として後方互換で保存されている。

---

## 物質の定義（7つの公理）

### 公理1 — レンズである

この物質は光を**散乱させない。屈曲・集光する**。すりガラス（blur）との違いはここにある。

- 表面は凸型スクワークル: 断面プロファイルは `⁴√(1-(1-x)⁴)`
- したがって屈折は**エッジに集中し、中央はほぼ素通し**になる
- **分散を隠さない（Prism の署名）**: 青は赤より強く曲がり、エッジで光は
  スペクトルに割れる（変位比 R 0.78 / G 1.0 / B 1.32・最大 6px）。
  制御条件は「エッジ帯のみ・構造の上でのみ視認」。無地の上に単独の色線が
  立つ状態は未制御であり不合格
- **個体差を持つ（生命徴・R13）**: 生き物は二つとして同じでない。同一部品でも
  一枚ごとに屈折の指紋がわずかに異なる（有機ノイズ ±12%・4個体プール）

> 演繹: 変位マップ生成・`falloff / scale / ca` の3パラメータ・色収差の上限

### 公理2 — 無色である

この物質は色を持たない。**見えている色はすべて背景から拾ったもの**である。
ガラス越しの世界は彩度がわずかに上がる（集光の帰結）が、面自体は着色しない。

- 着色は「ステンドグラス」という別の状態であり、**1画面に1箇所**、
  最重要のアクション背景にのみ許される
- ガラス上のラベルはモノクローム。色で語るのは背景の仕事

> 演繹: saturate は控えめな単一トークン・accent の1箇所規律・ラベルのモノクローム原則

### 公理3 — 環境を知覚する

この物質は背後にあるものを知っており、**自分を環境に合わせて調整する**。

- 背景が明るければラベルは沈み、暗ければ浮く（明暗反転）
- 背景が複雑なら輝度を補償して可読性を守る
- 環境は要素ごとに違ってよい。適応の単位はページではなく **surface（ガラス個体の文脈）**

> 演繹: `data-lg-surface` API・`--lg-ink` / `--lg-bcomp` のペア・Clear の 35% dim 層

### 公理4 — 仮想光源の世界に浮かぶ

ハイライトは飾りの縁取りではなく、**環境内の光源がこの物質に反射したもの**である。

- 光源は操作に応答して空間を動き、光が輪郭を回り込む
- **ハイライトは分光する**: リムは白一色ではなく、回り込みの先端が寒色・
  尾が暖色に割れる（プリズムを通った光として）
- 光源は**自律的には動かない**。誰も触れていないガラスの光は静止している。
  **唯一の例外（R13・注視の呼吸）**: focus-visible で注視されている間だけ、
  光は安静呼吸（3.6秒周期）でゆっくり明滅する — 注視は相互作用であり、
  応える光は自律ではない、という解釈。装飾の常時アニメ禁止は不変
- 光の応答は即時（1:1）。点灯と消灯だけがなだらか

> 演繹: `--lg-la`（角度）/ `--lg-li`（強度）の2変数光源 API・自律周回アニメの禁止

### 公理5 — gel の弾性を持つ

この物質は硬いガラスではなく、**押せばたわみ、離せば弾んで戻る** gel である。

- 変形には慣性がある: 押せば**縦に潰れ横に伸び**（体積保存の squash & stretch）、
  離せば低減衰バネ（ζ=0.42）で**ぷるんと揺れて**戻る（follow-through・R14）
- **追従には慣性がない**: 入力への応答は常に 1:1。
  gel は「変形の物理」であって「追従の遅延」ではない。
  カーソルにヌメっと遅れてついてくる演出は、この物質の物理に存在しない
- 操作の瞬間、物質は光を帯びる（公理4と連動）
- **近づくと瞳孔が締まる（生命徴・R13）**: hover でレンズがわずかに収縮する
  （×0.92）。押す前の予兆 = 素材がこちらに気づいている
- **潰れると光学が変わる（応答する光学・R12）**: 押されたレンズは平らになり、
  屈折と分散が 30% まで弱まる。離すとバネで揺り戻り、屈折が一度ゆらぐ。
  変形が見た目だけでなく**物性に及ぶ**ことが、この物質が生きている証拠

> 演繹: Spring クラス・押下 scale・粘性追従の全面禁止・アクティブピルの gel 移動

### 公理6 — 機能レイヤーにのみ存在する

この物質は**操作できるものの素材**である。読むもの・見るものはガラスにならない。

- インターフェースは2層: コンテンツ層（不透明な世界）の上に、
  ガラスの機能層（ナビ・操作系）が浮かぶ
- ガラスの上にガラスは積まない。ガラスの上の分離は塗りと透明度で行う
- 例外はひとつ: コンテンツ層の操作子（スライダー等）は**触れている間だけ**
  一時的にガラスになる。操作性の物質化であり、装飾ではない
- 希少性が価値である。ガラスが増えるほど、1枚のガラスの意味は減る

> 演繹: レイヤー規範・glass on glass 禁止・transient ガラス化・使用予算（02-layout 参照）

### 公理7 — 観測者に依存する（R16）

プリズムは自身の色を持たない。**どう見えるかは、観測者が決める。**

- トークンは「値」ではなく「範囲」を定義できる。分光の色相（±60°）・
  環境光の色相（±40°・装飾背景のみ）・光源の基準角（±15°）・
  呼吸の周期（2.6〜4.6s）・個体差プールは、観測者シードが範囲内で確定する —
  **二人として同じ画面を見ない**
- **hover に依存しない**: 環境光は開いた瞬間に、分光リムは**タップ（:active）でも**
  点灯する。SP の観測者も自分のプリズムに出会える
- 揺れてよいのは人格の軸だけ。**コントラスト・ガラス予算・レイアウト・
  状態色の意味・アクセントは不変**（憲法と lint が保証する）
- モード制: `data-lg-observer="personal"`（ブラウザごとに永続シード。
  LP・ツアー向け）/ 既定 `"fixed"`（`data-lg-seed` で決定的。製品・QA 向け）

> 演繹: 範囲トークン（sys/observer）・観測者シード・`LiquidGlass.observer()`

## 縮退の物理（フォールバックの定義）

Web では屈折を描けない環境がある。縮退は「劣化」ではなく、**物質が薄くなっていく**
と定義する:

1. **lens** — 完全な物質。屈折・分散・集光（Chromium）
2. **baseline** — 屈折を失った薄い物質。集光（saturate）と2光源のエッジ反射は残る。
   可読性とレイアウトはこの段階だけで完全に成立しなければならない
3. **opaque** — 物質が固化した状態（`prefers-reduced-transparency`）。
   透けないが、surface への適応は保ち続ける

屈折は「あれば嬉しい装飾」ではなく物質の本体だが、**本体を失っても道具として
壊れない**ことがシステムの責務である。

## 2つの相（バリアント）

| | Regular | Clear |
|---|---|---|
| 何か | 適応する標準の相 | 適応を捨てた高透過の相 |
| 屈折 | あり | あり（より素通し） |
| 環境知覚（公理3） | フル | なし（代わりに明背景で 35% dim 層を敷く） |
| 使い所 | ほぼ全て。テキストの多い部品 | リッチなメディア背景の上だけ |
| 禁則 | — | 明背景で dim なしは禁止 |

**同一画面で混ぜない。**それぞれ別の相であり、混在は物質の一貫性を壊す。

## この物質が「やらないこと」

- 画面中をガラス化する（公理6違反。希少性が価値）
- カーソル追従の粘性遅延（公理5違反。gel は追従しない）
- 自律的に回り続けるハイライト（公理4違反。光は操作への応答）
- エッジ帯を超えて広がる/無地の上で単独の色線になる未制御の分散（公理1違反）
- 白グラデーションの縁取りで「ガラスらしさ」を偽装する（公理4違反。
  光は光源から来る。縁取りはどこからも来ていない）
- 面への恒常的な着色（公理2違反。ステンドグラスの例外を除く）
