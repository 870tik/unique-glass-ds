# 03 — Motion: モーション仕様

根拠は [00-philosophy.md](00-philosophy.md) 公理4・5。
モーションはこのシステムの一級市民であり、静的な見た目と同格の仕様である。

## 大原則

**変形には慣性、追従には慣性なし。**

- 押されたガラスは gel としてたわみ、バネで復帰する（変形の物理）
- 入力への応答（リム光の角度・押下の開始）は常に 1:1 即時
- **カーソルに遅れてついてくる粘性演出は、いかなる形でも実装しない**

## gel（押下の物理）

```html
<button class="lg-glass lg-button" data-lg-gel>…</button>
<div class="lg-glass lg-card" data-lg-gel="0.985">…</div>  <!-- 押下スケール指定 -->
```

アニメーション技法（R14）: **Squash & Stretch + Follow-through**。

| フェーズ | 実装 | トークン |
|---|---|---|
| hover | 1.03 に膨らむ（気づき）。低減衰で揺れながら到達 | `--lg-motion-gel-hover-scale` |
| 押下 | 90ms の 1:1 で **縦0.90×横1.06 に潰れる**（体積保存の squash） | `squash-y / stretch-x` |
| 復帰 | 低減衰バネ（ζ=0.42）で**ぷるんと2〜3回揺れて**戻る | `--lg-motion-gel-wobble-zeta` |

- 部品の1ノブ `data-lg-gel="0.985"` は squash-y として解釈され、
  横伸びは体積保存で自動導出される
- **1:1 の押下即応は不変**（揺れるのは目標への到達だけ。追従遅延は存在しない）
- apple-quiet テーマは hover 膨らみ・squash&stretch をオフ、ζ を 0.65 に戻す

- バネは `LiquidGlass.Spring(value, k, zeta)` として公開。ナビのピル移動・
  モーダルの開閉も同じバネで動く（システム全体でひとつの物理）
- `prefers-reduced-motion` 時、バネはスナップ（即時到達）に落ちる

## 仮想光源（リム光）

- 光源は `--lg-la`（角度）/ `--lg-li`（強度）の2変数。`@property` 登録
  （**inherits: true** — 擬似要素がリムを描くため。false にすると Chromium で
  リムが消える。過去に踏んだバグ）
- hover でポインタ角度に **1:1 直結**してリムが輪郭を回り込む。強度 0.8、
  押下で 1.0（`--lg-light-hover-intensity / -press-intensity`）
- なめらかなのは**点灯と消灯だけ**（450ms ease）。角度はトランジションしない
- 誰も触れていないガラスの光は静止している。自律周回・常時アニメは禁止
  （批評で kill 済みの装飾）

## 応答する光学（R12・Prism 署名）

押下で**屈折そのものが変化**する。gel の潰れ（transform）と同時に、
変位スケールが `--lg-motion-gel-optics-press`（0.3）までバネで縮み、
離すとアンダーダンプで揺り戻る = 屈折が一度ゆらいで静止する。

- lens モード限定（baseline では gel のみ。縮退として自然）
- 初回押下時にフィルタを要素専有へ複製（共有キャッシュを汚さない）
- `data-lg-gel` が付いたガラスに自動で乗る。追加の記述は不要
- reduced-motion ではスナップ

## 物性の境界（R14 補遺）

| 物性 | 及ぶ範囲 |
|---|---|
| **弾性（gel: squash & stretch・揺れ）** | **操作できる全部品**（ガラスも塗りも。chip・pagination・icon-button・select・step に自動搭載） |
| **光学（屈折・分散・リム・瞳孔・呼吸）** | **ガラスのみ**（二層モデルの希少性はここで守る） |
| 静止 | 非インタラクティブな塗り（stepper の進行表示・breadcrumbs・badge 等）。押せないものは応えない |

## 生命徴 vital signs（R13・Prism 署名）

「少し生きている」を3つの機構で実装する。すべてトークンで無効化可能
（apple-quiet テーマは全オフ）:

| 機構 | 挙動 | 合法性 |
|---|---|---|
| 個体差 | 同一部品でも一枚ごとに屈折の指紋が違う（±12%・4個体） | 静的 = 公理内 |
| 瞳孔反射 | hover でレンズが ×0.92 に締まる（押す前の予兆） | 応答 = 公理内 |
| 注視の呼吸 | focus-visible の間だけリム強度が3.6s周期で明滅 | **公理4の唯一の例外**（R13） |

- 状態は press > hover > rest の優先で1本のバネに統合（vitals.js）
- reduced-motion: 呼吸は停止、反射・押下はスナップ
- **これ以上の「生きている風」装飾（アイドル揺れ・視線追従等）は禁止のまま**。
  生命徴は上記3つで完結し、追加は R 判断を要する

## 環境のモーション

- 背景（コンテンツ層）のドリフトやヘイズは合法。ゆっくり（数十秒級）、
  ガラス越しに屈折して見えることが目的
- `data-lg-animate` を付けた背景要素は IntersectionObserver で画面外停止される
- ガラス自体を環境で常時動かさない（動いてよいのは背景と、操作への応答だけ）

## 環境信号（R18）

素材は置かれた現実の環境にも応答する。すべて端末内で完結（詳細は docs/07 R18・08 A5.9）:

| 信号 | 挙動 | 実装 |
|---|---|---|
| 太陽同期 | 仮想光源の基準角が実際の太陽方位を追う（朝=右 145°、正午=既定 215°、夕=左 285°。夜は既定角） | 端末時刻のみ・近似 |
| 傾き応答 | 端末の傾きに光源が 1:1 追従（SP の hover 代替） | DeviceOrientation。iOS は `LiquidGlass.enableTilt()` |
| バッテリー | 残量 20% 以下（非充電）で呼吸半減・点灯減・押下光学が浅く | Battery API（ある環境のみ） |
| 懐き | 訪問日数で生命徴が開く（初訪 ~50% → 8日で全開） | localStorage 日単位・personal のみ |

観測者の角度個性（R16）は太陽の上に**オフセットとして残る** — 同じ時刻でも
二人の光源は違う。傾き応答は「追従には慣性なし」の大原則そのもの（1:1・遅延なし）。

## 遷移の語彙

| 遷移 | 動き | 実装 |
|---|---|---|
| タブ切替 | アクティブピルが gel バネで滑走 | `.lg-nav` 自動配線 |
| モーダル開 | scrim フェード + pane が scale 0.94 → 1.0 のバネ | `LiquidGlass.modal()` |
| モーダル閉 | フェード（バネなし。退場は軽く） | 同上 |
| field focus | 一時ガラス強調（rest 85% → 100%） | `.lg-field` |

## 実装ルール

- 新しいモーションを足すときは、まず「これはどの公理の帰結か」を書けること。
  書けない動きは装飾であり、原則却下
- duration・easing・バネ定数は必ずトークン参照。曲線の直値コピペ禁止
- `prefers-reduced-motion` 対応は任意ではなく必須。全アニメ停止 + バネはスナップ
